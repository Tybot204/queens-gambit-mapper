# Queens Gambit Mapper

Built for the Destiny 2 chess ARG.

## Prerequisites

- Node v22.14 (others probably work fine, just what I used)
- NPM or Yarn

## Installation

1. Clone the repo
2. Don't read the code, it's a mess and needs a huge refactor
3. Run `npm install` or `yarn install` to install dependencies
4. Run `npm update:verified` or `yarn update:verified` to pull the latest verified piece data from <https://tjl.co/queens-gambit-arg/data-verified.json>
5. Run `npm cluster` or `yarn cluster` to generate an grid of pieces
6. Copy / paste the output into <https://tjl.co/queens-gambit-arg/self-service-matches.php>
